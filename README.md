## 🍗 ShrimpDiet

<img src="assets/card-diet.svg" width="100%" alt="ShrimpDiet：拍一张饭，算出离增肌还差多少。">

<b>拍一张饭，算出离增肌还差多少。</b>拍照或写一句话描述这顿饭，视觉模型认出里面的食物，估算热量和蛋白质；一天提醒三次，按每日目标算出今天还差多少。主要是做给自己的，我想增肌！<br>
